Privacy Policy – Grocery Dad

Last updated: December 12th, 2025

This Privacy Policy describes how the application Grocery Dad (“the App”) collects, uses, and protects user information. By using the App, you acknowledge that you have read and understood this policy.

1. Information We Collect

1.1. Required Permissions

The App requests the following permission:

  • android.permission.RECORD_AUDIO

This permission is used exclusively to enable the voice search feature, allowing users to search for grocery items in the App’s internal database using voice commands.

1.2. Audio Data Handling

The App:

  • does not collect, store, or transmit any audio recordings to external servers,
  • uses the microphone only when the user intentionally activates the voice search feature,
  • processes audio locally on the device for the sole purpose of interpreting spoken search terms.

2. How We Use the Information

Audio input is used strictly for:

  • recognizing the user’s spoken commands,
  • searching for grocery items within the App’s database,
  • improving user convenience and navigation within the App.

3. Sharing of Information

The App does not share, sell, or transfer any audio data to third parties.

4. Data Storage

Grocery Dad does not store audio recordings on its servers or in the cloud.

5. Data Security

The App relies on industry-standard Android security measures to protect user information.

6. User Rights

Users may deny microphone access, disable voice search, request information, or uninstall the App.

7. Changes to This Privacy Policy

We may update this Privacy Policy periodically. Updates will appear on this page.
